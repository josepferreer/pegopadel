# pegopadel · Punt de partit

Landing del torneig de pàdel del Club de Pàdel Pego (dissabte 12 de desembre de 2026).

Web estàtica: `index.html` + `assets/`. Es publica amb GitHub Pages des de la branca `main`.

## Editar

- Els textos i l'estil es toquen a `index.src.html`.
- Després s'executa `python build.py`, que genera `index.html` inserint-hi el logo SVG (`assets/logo-symbol.svg.txt`).

## Crèdits

- Fotos: [Pexels](https://www.pexels.com) (llicència Pexels, ús lliure).
- Tipografies: Instrument Serif i Montserrat (Google Fonts), Glacial Indifference (OFL). Logotip dibuixat a partir d'Unbounded (OFL).
